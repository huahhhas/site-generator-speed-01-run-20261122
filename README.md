A fast, dependency-free drop-in for makefun-site 1.0.0: `solve.js` renders a site's Markdown sources, front matter, templates, tags and index pages into exactly the same output tree, byte for byte — with a single-pass Markdown scanner, a hand-rolled front-matter parser, precompiled templates and per-run caches, so it runs several times faster than the house baseline.

## Run it

```sh
node main.ts
```

`main.ts` reads every case from `/input/cases.json` (or `$MAKEFUN_INPUT_DIR`) and writes `/output/answers.json` (or `$MAKEFUN_OUTPUT_DIR`).
